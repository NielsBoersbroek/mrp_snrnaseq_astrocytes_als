About this analysis

In this script, I preprocessed the astrocytes (i.e. Normalization, variable feature selection, dimensionality reductions, etc.), cluster them and annotate these clusters. For annotation, I examined known astrocyte markers and GO-term enrichment of clusters.

dims

I set deliberately set the dimensions high, as I’d like to include information and increasing to 40 did not highly affect UMAP or clustering.

number_of_top_pathways

marker genes

theme_quarto() and theme_manuscript()

I created my own themes to add to figures. theme_quarto() is used to add themes to figures as displayed in the Quarto document and saved to disk as .pdf or .png. theme_manuscript() is used to add themes to figures as they will end up in the manuscript. I can already add arguments with theme() or specific themes (e.g. theme_classic(), my personal favourite) to plots; adding theme() afterwards keeps whatever was added in theme() before it, unless I specify that arugment here - that’s why I allowed to specify some things within my functions as well.

theme_quarto <- function(
    legend_position = "right", 
    plot_title = element_blank()
    ) {
    theme(
      plot.title = plot_title,
      legend.position = legend_position
    )
}

theme_manuscript <- function(
    legend_position = "none",
    plot_title = element_blank(),
    axis_title_size = 8,
    axis_text_size = 6
    ) {
    theme(
      plot.title = plot_title,
      legend.position = legend_position,
      axis.title = element_text(size = axis_title_size),
      axis.text = element_text(size = axis_text_size),
      legend.key.size = unit(0.4, "cm"), 
      legend.text = element_text(size = 8),
      legend.title = element_text(size = 9)
    )
}

save_plot()

This document displays all the figures I make, but I also want them saved to disk — both as .png and .pdf. I only need to provide the ggplot object, a filename (without extension), and optionally the width and height of the figure and additional arguments put into themes.

The figures for my written report contain subfigures spread across multiple scripts. Since I want to assemble these panel figures via R code rather than by hand, save_plot() can also optionally save the plot object itself to disk as an .rds file, for a final script to later combine with patchwork. Set figure to the name the figure should carry in the report (e.g. "SF1A") to trigger this; leave it NULL (the default) to just save the .png/.pdf as normal.

A live ggplot object carries its underlying data along with it — for plots built from large Seurat objects, this can balloon the saved file to gigabytes. To avoid this, save_plot() converts the object to a grob (a static, pre-rendered drawing, with no data attached) before saving it as .rds. This is controlled by the grob argument, and defaults to TRUE, since converting a small plot costs nothing but forgetting to convert a large one is expensive. Set grob = FALSE only if a later step specifically needs the original, live ggplot object rather than its rendered form.

save_plot <- function(
    p, filename, 
    width = 10, height = 6, 
    figure = NULL, grob = TRUE, apply_theme = TRUE, 
    add_tag = TRUE, tag_text_size = 14,
    legend_pos_manuscript = "none"
    ) {
  ## Save image on disk as png and pdf
  # Add Quarto-specific theme, unless the plot has its own custom theme
  if (apply_theme) {
    p_image <- p + theme_quarto()
  } else {
    p_image <- p
  }
  file_png <- file.path(dir_fig, paste0(filename, ".png"))
  ggsave(file_png, p_image, width = width, height = height, dpi = 150)
  file_pdf <- file.path(dir_fig, paste0(filename, ".pdf"))
  ggsave(file_pdf, p_image, width = width, height = height, dpi = 150)
  
  ## Save the ggplot object on disk as an rds file 
  if (!is.null(figure)) {
    # Add tag if needed
    if (add_tag) {
      tag <- str_extract(figure, "[A-Z]$")
      p <- p + 
        labs(tag = tag) + 
        theme(
          plot.tag = element_text(
            face = "bold", 
            size = tag_text_size, 
            hjust = 0, vjust = 0
            )
        )
    }
    # Add manuscript-specific theme, unless the plot has its own custom theme
    if (apply_theme) {
      p <- p + theme_manuscript(legend_position = legend_pos_manuscript)
    }
    file_rds <- file.path(dir_man, paste0(figure, ".rds"))
    # Convert the object to a grob if needed
    if (grob) {
      p <- ggplotGrob(p)
    }
    # Save on disk
    saveRDS(p, file_rds)
  }
}

print_tabset()

Quarto cannot cross-reference figures that are made inside a loop. To still display the plots of a loop in this document, I collect them in a named list and show them as tabs with print_tabset(). The names of the list become the tab titles. It also accepts data frames (shown as a table). This function writes raw Quarto markdown, so the chunk that calls it needs the chunk option #| output: asis. heading_level should be one deeper than the heading above the chunk.

print_tabset <- function(obj_list, heading_level = 3) {
  cat("::: {.panel-tabset}\n\n")
  for (nm in names(obj_list)) {
    cat(strrep("#", heading_level), " ", nm, "\n\n", sep = "")
    obj <- obj_list[[nm]]
    if (inherits(obj, "ggplot")) {
      print(obj)
    } else if (is.data.frame(obj)) {
      cat(knitr::kable(obj, format = "pipe"), sep = "\n")
    }
    cat("\n\n")
  }
  cat(":::\n\n")
}

variable_feature_selection()

I want to remove sex chromosome genes and mitochondrial genes in the FindVariableFeatures step. This does not remove these genes from all further analysis, but it just prevents these genes from affecting dimensionality reduction and subsequent clustering. As this involves quite a lot of steps, I decided to write a function, instead of running all these lines in a chunk below.

You need to provide the Seurat object and a vector with the sex chromosome genes of your particular seurat object.

variable_feature_selection <- function(seu, sexgenes) {
  # Create a vector of all genes
  genes <- rownames(seu@assays$RNA$counts)
  
  # Create a vector of mitochondrial genes
  mitogenes <- genes[grep("^MT-", genes)]
  
  # Create a new Seurat object with mitochondrial and sex chromosome genes removed
  genes_to_remove <- c(mitogenes, sexgenes)
  genes_boolean <- (genes %in% genes_to_remove)
  gene_selection_counts <- seu@assays$RNA$counts[!genes_boolean, ]
  gene_selection_seu_obj <- CreateSeuratObject(counts = gene_selection_counts)
  gene_selection_seu_obj <- NormalizeData(gene_selection_seu_obj)
  
  # Run variable feature selection on the gene-selected Seurat object
  gene_selection_seu_obj <- FindVariableFeatures(
    gene_selection_seu_obj,
    selection.method = "vst",
    nfeatures = 2000
  )
  # Create a vector of the variable features of the gene-selected Seurat object
  variable_features <- VariableFeatures(gene_selection_seu_obj)
  # Transfer variable features to main seurat object
  VariableFeatures(seu) <- variable_features
  
  # Remove the objects which are no longer needed to save memory
  rm(gene_selection_counts)
  rm(gene_selection_seu_obj)
  
  # Return the seurat object with variable features set
  seu
}

top_markers <- function(markers, cluster_select = NULL, n_genes = 10) {
  if (!is.null(cluster_select)) {
      markers |>
        filter(cluster == cluster_select) |>
        filter(p_val_adj < 0.05) |>
        slice_max(avg_log2FC, n = n_genes)
  } else {
    stop("You did not provide a cluster to select")
  }
  
}

prepare_gsea() and gsea_pathway_selection()

If the test FindAllMarkers() has been run, I need to subset a cluster, so the identity argument should provide what identity/cluster we are interested in. If the test FindMarkers() has been run, this is not a problem, but this does not automatically have a column gene; these are rownames and should become a column.

Two ways to sort: - logfc: directly by logfc - signed_logp: -log10(p-value), with the sign (+/-) of the logFC

gsea_pathway_selection() is a quick little function which extracts the most upregulated and downregulated pathways of a FGSEA results table, mostly for visualization. The numbers for upregulated and downregulated pathways are defined in the “Define variables” section

prepare_gsea <- function(markers, findallmarkers = FALSE, identity = NULL,
                         sort = "logfc") {
  if(findallmarkers) {
     markers <- markers |>
       filter(cluster == identity)
  } else {
    markers <- markers |>
      rownames_to_column(var = "gene")
  }
  # Remove non-SYMBOL genes
  markers <- filter(markers, !str_detect(gene, "ENSG"))

  # Sort genes based on selected sorting method
  if (sort != "logfc" & sort != "signed_logp") {
    stop("You did not select a valid sorting method")
  } else if (sort == "logfc") {
    # Rank by logFC
    markers <- arrange(markers, desc(avg_log2FC))
    # Extract a named vector of the ranked genes
    gene_scores <- markers$avg_log2FC
    names(gene_scores) <- markers$gene
  } else if (sort == "signed_logp") {
    markers <- markers |>
      mutate(
      rankings = sign(avg_log2FC)*(-log10(p_val_adj)),
      rankings = case_when(
        rankings == Inf ~ 350, # a little higher than maximum value
        rankings == -Inf ~ -350,
        .default = rankings
        )
      ) |>
      arrange(desc(rankings))
    # Extract a named vector of the ranked genes
    gene_scores <- markers$rankings
    names(gene_scores) <- markers$gene
  }

  gene_scores
}

gsea_pathway_selection <- function(gsea_results, n_up = 10, n_down = 0) {
  top_pathways_up <- gsea_results |> 
    filter(padj < 0.05) |>  
    slice_max(NES, n = n_up) |>
    pull(pathway)
  top_pathways_down <- gsea_results |>
    filter(padj < 0.05) |>
    slice_min(NES, n = n_down) |>
    pull(pathway)
  top_pathways <- c(top_pathways_up, rev(top_pathways_down))
  top_pathways
}

boxplot_composition()

boxplot_composition() creates the visualizations of cell composition. The input is the dataframe cell_counts, which is created in the first chunk under the header Cell Composition Analysis.

boxplot_composition <- function(cell_counts, variable = "AnonymousID") {
  # For ggplot2, I need to pivot longer, so that each count becomes a row
  cell_counts_ggplot <- cell_counts |> 
    mutate(
      total_counts = `GM Astrocyte` + `WM Astrocyte 1` + `WM Astrocyte 2`,
      `GM Astrocyte` = `GM Astrocyte` / total_counts,
      `WM Astrocyte 1` = `WM Astrocyte 1` / total_counts,
      `WM Astrocyte 2` = `WM Astrocyte 2` / total_counts
      ) |>
    pivot_longer(
      cols = c("GM Astrocyte", "WM Astrocyte 1", "WM Astrocyte 2"),
      names_to = "cellstate",
      values_to = "Proportion"
    )
  
  p_box <- ggplot(
    cell_counts_ggplot, 
    aes(x = cellstate, y= Proportion, fill = !!sym(variable))
    ) +
    geom_boxplot(alpha = 0.7) +
    geom_point(
      aes(group = !!sym(variable)), colour = "grey20", size = 0.6,
      position = position_jitterdodge(jitter.width = 0.4, dodge.width = 0.8)
      ) +
    theme_classic()
  
  p_box
}

I assessed multiple clustering resolutions and chose to continue with cluster resolution 0.15, as the three clusters created with resolution 0.15 remain robust over increasing resolutions (nicely illustrated in Figure 3). Cluster interpretation and annotation

Removal cluster 4

I removed cluster 4, because the markers of that cluster mostly were mitochondrial RNA. I found that that was the case through Seurat’s FindAllMarkers().

Seurat’s FindAllMarkers()

I used Seurat’s function FindAllMarkers() to interpret clusters. By default, FindMarkers() sets threshold for the minimum log-Fold Chance threshold (logfc.threshold) and minumum percentage of cells expressing the gene (min.pct). I am generally in favour of setting these thresholds, but I will later use the output for Gene Set Enrichment Analysis (GSEA), which also requires values for lowly expressed genes. Therefore, I run FindAllMarkers() with loose thresholds (logfc.threshold = 0 and min.pct = 0.1). Results of top markers are displayed below, using the function top_markers() which I defined above. I also saved a csv with the full results on disk, so I could inspect the full list myself.

# Run FindAllMarkers, but with very loose thresholds: I'll run GSEA of GO-terms
# on it, which means I'll want a gene score of almost all genes
markers <- FindAllMarkers(
  seu,
  logfc.threshold = 0,
  min.pct = 0.1
)

## Extract a table of top markers and save full table to disk
# I put top markers per cluster in a list to later display it as a tabset
list_markers <- list()
# Extract the number of clusters present in each resolution
marker_levels <- markers |>
  distinct(cluster) |>
  mutate(cluster = as.numeric(as.character(cluster)))
# The previous step created a dataframe, so select the column 'cluster'
for (i in marker_levels$cluster) {
  # Extract table of top markers and store in list
  list_entry_name <- paste0("Cluster ", i)
  list_markers[[list_entry_name]] <- top_markers(markers, cluster_select = i)
  # Write to disk as csv

  file_csv <- file.path(dir_tab, file_csv)
  markers |>
    filter(cluster == i) |>
    write_csv(file_csv, col_names = TRUE, quote = "none")
}

I came to the same conclusion using GO-terms. To test enrichment of pathways, I loaded in GO terms with the msigdbr package and used GO:Biological Processes (GO:BP). Some caveats:

  1. The Seurat object contacts both genes given with SYMBOL and with EnsebmlID. SYMBOL genes are the standard, the EnsembleID genes in our data are either lnc-RNAs, transcript isoforms or other things - which are not in the GO:BP anyways. These are thus removed from the analysis.
  2. For GSEA of GO terms, I need to sort genes, which can be done using either logFC or p-value. I designed my function to allow for both - either directly logFC or sign(logFC)*log(p). I mainly focused on direct logFC, mostly based on this GitHub discussion and the sources referenced there, but I acknowledge both methods have their limitations.

Cell composition analysis

I will now examine cell composition with scCODA. The first part is done in R: I need to prepare it in a tidy format from my seurat object. I will then perfrom the statistical test with scCODA, which is in Python, and provide visualizations back in R with ggplot2 (ggplot2 over matplotlib any day of the week), for which I defined the function boxplot_composition().

First create a count table. ggplot2 and scCODA require slightly different input: for ggplot, I need to pivot_longer. I’ll do that in the bar_freq function instead of here.
